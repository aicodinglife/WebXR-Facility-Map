Summary
We're a design & software studio building a proof of concept for a client demo. We need an experienced WebXR/Three.js developer for a fast, self-contained build. This is a demo, not production — speed and visual impact matter more than architecture.

What you're building

A browser-based interactive map of a large sports/leisure facility, navigable in a Meta Quest headset.

3D scene generated from a 2D CAD floor plan. We provide the file. You extrude footprints into a clean, readable 3D environment walls, pool volumes, circulation. Stylised, not photoreal. No photogrammetry or 360° capture involved.
Map-first entry. The app opens directly into the scen no landing page, no menu screen.
Named interactive zone, main pool, training pool, changing rooms, entrance, reception, spectator seating. Hover highlights, selection opens an info panel.


Technical requirements
Frontend only, no database, no backend.

We provide: CAD file, zone naming, brand direction, Arabic copy, API key.

Requirements: Shipped WebXR work we can open in a browser now. Include live links — not video reels. Applications without a working demo URL won't be reviewed. 

Arabic a plus, not required
